## 🛡️ About Me

Lead Cybersecurity Engineer with over **14 years of experience in IT**, including **7+ years specializing in Information Security**, Security Operations (SOC), Incident Response, and Vulnerability Management. 

Experienced in leading EDR/XDR deployments, penetration testing, threat hunting, and aligning enterprise security architectures with frameworks such as **NIST CSF**, **ISO 27001**, **MITRE ATT&CK**, and **OWASP**.

- 📍 **Location:** Dublin, Ireland
- 🎯 **Core Focus:** Security Operations (SOC), EDR/XDR Deployment, Cloud Security & Threat Analysis
- 📜 **Key Certifications:** CrowdStrike Certified Falcon Administrator (CCFA) | Certified Ethical Hacker (CEH) | Certified LLM Security Professional (CLLMSP)
